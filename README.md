# Cafe Park Avenue — Landing Page

Адаптивний вебсайт (лендинг) для крафтової кондитерської та кав'ярні **«Cafe Park Avenue»** (м. Монастирище, вул. Соборна, 132), розроблений у межах курсу **«Технології веброзробки та дизайну»** (Лабораторні роботи №5–8).

## Демо-посилання (Live Deploy)
- **GitHub Pages:** https://eraami0n.github.io/Cafe-Park-Avenue/
- **Netlify:** https://cafe-parkavenue.netlify.app/

## Основні можливості
- Адаптивна Mobile-First верстка (смартфони, планшети, десктоп)
- Семантична структура HTML5 та валідність за W3C
- Каталог авторських десертів, круасанів та тортів із візуальними картками
- Інтерактивний конструктор торта на замовлення
- Інтегрована відеопрезентація YouTube, інтерактивна карта Google Maps та сайдбар живих інформерів (`<aside>`)
- Конверсійна форма замовлення дегустаційного сертифіката

## Стек технологій
- **HTML5** — семантична розмітка сторінки
- **CSS3** + **Tailwind CSS** — стилізація, брендова дизайн-система та адаптивність
- **JavaScript** — інтерактивні елементи інтерфейсу
- **Git / GitHub** — контроль версій та історія розробки
- **GitHub Pages** & **Netlify** — хостинг та безперервне розгортання (CI/CD)

## Структура проєкту
```text
Cafe-Park-Avenue/
├── index.html          # Головна сторінка лендингу
├── css/
│   └── style.css       # Кастомні стилі, змінні та анімації
├── assets/
│   ├── icons/          # SVG-іконки інтерфейсу
│   └── images/         # Оптимізовані зображення десертів та логотип
├── .gitignore          # Виключення службових та тимчасових файлів
└── README.md           # Документація проєкту
```

## Локальний запуск
1. Клонуйте репозиторій:
   ```bash
   git clone https://github.com/Eraami0n/Cafe-Park-Avenue.git
   cd Cafe-Park-Avenue
   ```
2. Відкрийте файл `index.html` у браузері або запустіть через розширення **Live Server** у Visual Studio Code.
